# Default NGs benchmark

`my_NGs_Per0.5.mat` is the processed NGs dataset and fixed observed-view pattern supplied with the original experiments. It contains 500 samples, five classes and three views. This file is copied unchanged for the default reproducibility run.

The MAT variables are `data` (view feature matrices), `index` (observed sample indices per view), and `truelabel` (evaluation labels). Features are in rows, samples in columns. Training receives only the number of classes, not the label vector.

`Per0.5` corresponds to nominal missing rate 0.5. More generally, **missing rate = 1 - Per**. These filenames do not say that exactly half of all sample-view entries are absent; the actual entry and sample fractions are reported by the loader.

The file's SHA256 and provenance are recorded in `PROVENANCE.json`. This is a processed benchmark copy; no new missing pattern or synthetic substitute is generated by the default command. Dataset provenance is distinct from code authorship, and no new ownership or data license is asserted.
